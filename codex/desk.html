작업실 설정과 안내

HTML 위젯은 브라우저 전용입니다. 서버 셸이나 네이티브 Claude Code Mod가 아닙니다. 위젯은 allow-scripts만 허용한 sandbox iframe에서 실행되며 네트워크 연결, 상위 페이지 접근, 폼 전송, 외부 프레임을 CSP로 차단합니다.

Native Mods 호환 기준은 2.1.291, 최소 2.1.287이지만 이 화면이 Mods 설치 상태를 의미하지는 않습니다. 현재 HTML 위젯은 설치형 Mod와 분리된 기능입니다.

Claude 슬롯은 공개 데이터 작업 경로를 전제로 표시합니다. 인증 상태는 이 화면에 저장하거나 추정하지 않으며 각 CLI에서 별도로 확인합니다.

터미널 창을 닫아도 화면에서만 분리되며 서버의 터미널 세션을 종료하지 않습니다. 에이전트 변경과 다시 연결에서만 해당 iframe을 다시 탐색합니다.
